# Legends of Wand & Sword · 杖剑传说

服务端权威的 Web 放置手游（Playable 原型）：Go 单二进制权威服务 + 原生 Canvas 部件动画前端，单端口同源部署，支持多端接入。

当前最新归档版本：**v1.9.44**（历史归档分支保留，按需拉取）。

## 分支说明

本仓库按「代码 / 资源」分离存放，克隆时按需拉取对应分支：

### 拉取方式

```bash
# 代码
git clone -b code/v1.9.44 https://github.com/AngelicaeTao/legends-of-wand-sword.git

# 资源（放入同一工作目录，按 assets 分支 README 的回填映射还原）
git clone -b assets/v1.9.44 https://github.com/AngelicaeTao/legends-of-wand-sword.git assets
```

## 快速开始

```bash
cd server && go build -o ../data/zjcs-server .
cd .. && ./data/zjcs-server -addr :3000 -config configs -web web/index.html -res web/res
# 打开 http://localhost:3000
```

资源需从 `assets/v1.9.44` 回填到 `web/res/`，映射表见 assets 分支的 `README.md`。

## 技术概览

- **服务端**：Go，单二进制，HTTP + WebSocket，存档落 JSON；战斗/掉落/宝箱/装备/仓库/副本全部服务端权威
- **前端**：原生 JS + Canvas，部件化骨骼动画（parts/actions 配置驱动），单通道 UI 状态机
- **大世界**：6 个 15360×8640 世界，地形图 + 通行掩码硬碰撞；渲染按 1280×720 分块纹理 + 异步裁剪 + LRU，规避 GPU 纹理上限
- **多人**：WS 10Hz 快照，`worldId+channel` 分线（40 人/线），断线退避重连

### A4. 装备系统（equipment.json）

4 槽：武器/头盔/护甲/饰品。5 品级倍率：普通 ×1.0（灰）→ 精良 ×1.25（蓝）→ 稀有 ×1.6（紫）→ 史诗 ×2.1（橙）→ 传说 ×2.8（红）；v1.9.42 另加彩虹/暗影/混沌 3 档与升品入口。

基础属性：武器 ATK+10；头盔 HP+60/DEF+3；护甲 HP+100/DEF+6；饰品 暴击+3%/ATK+4。
强化：成本 `= 1200 × 1.35^当前等级`，每级属性 +8%，上限 +15，**必成功**（确定性成长）。

## Part B · 设计档案（决策与 rationale）

> 以下来自设计阶段文档，是实现的溯源与判断依据。部分内容已在 Part A 落地，部分为设计构想/待实现项，已标注。
> 每个决策都遵守：**先写 fun hypothesis → design pillars → 具体系统**；数值全部带 rationale 或标 [PLACEHOLDER]。

### B1. 核心设计哲学

**Fun hypothesis**：这款放置手游好玩的核心是——**大世界探索的"发现感"（路网里藏着怪和箱）+ 服务端权威战斗的"确定性"（离线也在变强）+ 捏出自己角色的"表达感"**。

**Design pillars**：

| 支柱 | 体验标准 |
|---|---|
| 通道网驱动探索 | 地图复杂度来自通道路网拓扑，不是面积；狭窄通道制造遭遇张力，局部破墙开阔节点制造惊喜 |
| 所见即所得的成长 | 变强看得见——装备穿在身上、技能 BD 生效、转职不丢脸 |
| 服务端权威 | 战斗/掉落/入账/时间戳全在服务端，客户端不可伪造 |
| 数值可改 | 配置驱动，改 JSON 不改代码；所有数值有 rationale 或 [PLACEHOLDER] |

### B2. 地图设计（设计决策）

- **横版 XY 正俯视连续移动**，非格子回合制；遇怪按钮选择交战，探索与战斗分离。
- **复杂度来自路网**：主通道 384px（=角色显示 128px × 3）、支路 256px、暗道 192px；角色相对世界足够小。
- **分块绘制再拼接**：2×2 地形块拼成 15360×8640；地形图与通行掩码同源（白 255 可走 / 黑 0 墙），程序员按掩码定移动边界。
- **局部破墙开阔节点**：在狭窄通道网中局部打开大空间，制造探索节奏对比。W4 冰霜高原开阔区偏多为差异化设定。
- **6 世界固定点位随机刷新 + 跨世界通道 + 传送 CD + 实时多人**。

### B3. 角色创建与换装（设计档案）

**Fun hypothesis**：让玩家第一分钟捏出"像自己"的角色，之后每次换装/转职都在同一具身体上看见变化。

| 决策 | 内容 |
|---|---|
| 6 槽创建 | 脸型/发型/上衣/裤子/鞋子/帽子，各 4 选项，4⁶ = 4096 组合；脸与发型拆为独立槽（v4.1），避免绑定无法换发 |
| 两套外观 | 家园=创建时休闲装（`appearance.homeLook`）；探索/战斗=装备 4 槽覆盖外观；场景切换自动切 |
| 转职零成本 | 转职只换技能池和装备适配，脸型/休闲装永久保留 |
| 技能 BD 过滤 | 技能库按当前职业过滤，只显示可选；进阶解锁高阶；转职后原职业技能自动卸下 |
| 画布升级 | 角色逻辑画布 32×48 → **64×96**，`scaleRoot` 4 → 2，屏幕显示仍 128×192（比例锚点不变）；AI 图压进 32×48 五官全糊，64×96 保住细节 |
| v5 风格回退 | 精致 AI 像素降 16 色后五官糊、判定太丑 → 回退「第一版法师」大色块像素风：大眼睛圆脸、平涂、硬描边、≤16 色；NEAREST 降采样 + 自适应 MEDIANCUT 量化 |

叠放顺序：`face → hair → hat → top → pants → shoes`；数据存选项 id 不存图片路径（换素材不改存档）。
